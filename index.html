About

I'm working toward my first SOC analyst / blue team role. I built this home lab so I could practice security work instead of only reading about it.

I use Suricata to detect network activity, Splunk to search and understand alerts, Nessus to find security problems, and VirusTotal to check suspicious IP addresses.

For each project, I create a controlled test, look at the alerts and logs, investigate what happened, and document what I found. The screenshots on this site show the actual work from my lab.
